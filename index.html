CI/CD con GitHub Actions

Página web estática desplegada automáticamente en Surge.sh mediante integración continua al hacer push al repositorio de GitHub.

1. Repositorio Git

Código fuente versionado con Git y alojado en GitHub con rama principal main.

2. GitHub Actions

Workflow automatizado que detecta cada push y ejecuta el pipeline de despliegue.

3. GitHub Secrets

Token de autenticación protegido mediante SURGE_TOKEN sin exponer credenciales.

4. Surge.sh Hosting

Servidor web estático rápido y seguro con soporte SSL automático.
